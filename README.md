# Polytech Schedule Bot & Puffinsgram

## О проекте

Этот проект представляет собой многофункционального Telegram-бота, созданного для студентов Политеха. Он решает две основные задачи:

1.  **Парсинг расписания:** Бот умеет получать актуальное расписание занятий с официального сайта университета (`ruz.spbstu.ru`). Пользователи могут запросить расписание для своей группы на сегодня или на неделю, а также экспортировать его в формате `.ics` для добавления в личный календарь (Google Calendar, Apple Calendar и др.).

2.  **Есть ли пышки?:** В проекте реализован уникальный сервис для отслеживания наличия пышек в Политехе. Специальный парсер отслеживает сообщения в одноимённом Telegram-канале и сохраняет информацию о наличии или отсутствии пышек в базу данных. Эта информация затем используется для:
    *   Ответа на запросы пользователей через бота.
    *   Отображения статистики и графиков наличия пышек за последние 2 недели на встроенной веб-странице (Telegram Web App), доступной прямо из чата с ботом.

Вся информация хранится в базе данных MySQL, а для взаимодействия с ней используется SQLAlchemy.

## Быстрый старт (с Docker)

Это основной и рекомендуемый способ для развертывания проекта на сервере.

### 1. Подготовка
- Установите [Docker](https://docs.docker.com/engine/install/) и [Docker Compose](https://docs.docker.com/compose/install/) на ваш сервер.
- Склонируйте репозиторий: `git clone <URL вашего репозитория>`
- Перейдите в папку проекта: `cd polytech-bot-featured`

### 2. Настройка окружения
Создайте файл `.env` в корневой папке проекта и заполните его по примеру. **Важно:** `DB_HOST` должен остаться `db`, так как это имя сервиса в Docker Compose.

```env
# Токен вашего Telegram-бота от @BotFather
BOT_API_KEY=YOUR_BOT_TOKEN

# ID вашего Telegram-аккаунта для получения уведомлений
ADMIN_ID=YOUR_ADMIN_ID

# --- Настройки базы данных MySQL (для Docker Compose) ---
DB_HOST=db
DB_PORT=3306
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_NAME=polytech_bot_featured
DB_ROOT_PASSWORD=your_strong_root_password # Пароль для root пользователя MySQL

# --- Настройки для экспорта в календарь (SMTP) ---
SMTP_HOST=smtp.your-mail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@example.com
SMTP_PASSWORD=your-email-password

# --- URL для Web App ---
# Укажите ваш домен, на котором будет работать Nginx
WEBAPP_URL=https://your-domain.com
```

### 3. Запуск
Выполните сборку и запуск контейнеров в фоновом режиме:
```bash
docker-compose up --build -d
```
Для просмотра логов используйте `docker-compose logs -f bot`.

## Локальная разработка (без Docker)

Этот способ подходит для разработки и отладки на вашем локальном компьютере.

### 1. Создание и активация виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` (можно использовать тот же, что и для Docker, но `DB_HOST` должен быть `localhost` или `127.0.0.1`). Также вам понадобится локально установленный и запущенный сервер MySQL.

### 4. Запуск проекта (Бот + Веб-сервер)
```bash
python -m tg_bot.start
```

## Тестирование

Проект покрыт юнит- и интеграционными тестами с использованием `pytest`. Тесты проверяют ключевую логику парсинга и взаимодействия с базой данных.

Для запуска всех тестов выполните одну команду:

```bash
pytest
```
